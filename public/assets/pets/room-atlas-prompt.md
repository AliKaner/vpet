# Room asset atlas

Generated with the built-in image generation tool and kept separate from pet atlases. The 4 x 2 transparent atlas contains sofa, coffee table, pet bed, floor lamp, rug, bookshelf, framed pet poster and disco ball. The `RoomScene` component uses percentage positions so the same objects are displayed behind pets on Home and on the Room page.
