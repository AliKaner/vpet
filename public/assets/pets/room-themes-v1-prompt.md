# Furniture collections

Generated with built-in imagegen; reference: room-isometric-v2.png. Original artwork preserved.

4 columns × 4 rows. Columns: reading armchair, wardrobe, fireplace, ottoman. Rows: Forest Cottage (sage/oak/leaves), Seaside (blue/whitewashed wood/shells), Strawberry (pink/cream/flowers), Midnight (navy/walnut/brass/moons). True transparent background, matching detailed pixel-art texture and isometric perspective. No text/grid/ground tiles. Each item centered within its equal square cell with generous transparent gutters.

Packing correction: preserve all designs/colors/order; shrink objects by 30% within each cell, fitting the central 65% of its width and height. Nothing crosses cell boundaries. Prioritize transparent space around tall wardrobes and fireplaces.

Runtime images are generated by `npm run assets:room`: 1024px wide, nearest-neighbor sampling, WebP quality 82, lossless alpha. Content-hashed URLs are preloaded from HTML and cached immutably. PNGs remain source assets and are not downloaded by room rendering. Combined runtime budget for all four atlases: 600 KB, checked with `npm run test:room`.
