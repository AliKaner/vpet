# Animated pets

Final set: 12 transparent PNG atlases, 252 frame cells. Native tool output is 1254 x 1254 pixels; the renderer uses percentage-based grid coordinates. Nine color/animal combinations share the same animation playback rules.

Validation: `npm run test:pets` checks neutral-to-action-to-neutral timelines, mood priority, appearance persistence, species validation, and refusal of unauthorized updates. `scripts/pet-browser-check.mjs` exercises the real React preview with Edge CDP on port 9234 and Vite on port 5178, including all 18 species/action flows, appearance switching, emotion loops, mobile layout and reduced motion.

Correction prompt applied separately to the three mood atlases: Preserve the exact 6x6 grid, alpha, poses, sizes and positions. Remove brown mud patches only from happy sprites in columns 3-4 of rows 2, 4 and 6. Restore natural clean colors. Preserve mud and odor marks on dirty sprites in columns 3-4 of rows 1, 3 and 5. Change nothing else.

Generated with the built-in image_gen tool. Original art remains in ../pet-atlas-v2.png.

Nine appearance atlases: cat-classic, cat-silver, dog-classic, dog-chocolate, bird-classic, bird-sunny, snake-classic, mouse-classic, horse-classic. Each has a 4 x 4 grid: idle, feed, species-specific social action, cleaning. Four genuinely different drawings per row. Playback starts and ends on cell 0 and reverses transition frames before returning to the idle loop. Completion is emitted by playback, not a separate wall-clock timeout.

Three emotion atlases: moods-companions (cat/dog/bird), moods-small-friends (snake/mouse/horse), moods-variants (silver cat/chocolate dog/yellow bird). Each has a 6 x 6 grid, two rows per species. First row: hungry pair, dirty pair, lonely pair. Second: scared pair, happy pair, calm pair. Emotional idle uses paired drawings. Critical health selects scared; otherwise the lowest need below 40 selects hungry, dirty or lonely; well-cared-for happy pets use happy.

Preview: run npm run dev and open /animation-preview.html. No account or database writes needed in the studio. Reduced-motion preference keeps drawings still. Runtime assets are PNGs with preserved transparency; no CSS color filters.

Each character fully contained within central 192x192 of its cell (32 pixel margin on ALL sides); same centered anchor and foot baseline in every cell, same size, no grid/text/shadows/background. These are sequential hand-drawn animation frames with genuinely different limb/face/tail drawings, NOT four identical drawings shifted or rotated. Row 1 IDLE: four subtle consecutive frames showing tail tip moving, eyelids blinking, ear twitch; frame 1 neutral open eyes, frame 2 anticipation/half blink, frame 3 closed blink and tail/wing movement, frame 4 eyes open recovering. Row 2 FEED: four frames progressing from neutral attentive pose toward head dipping to bowl then chewing; first barely leaning, second midway, third full action, fourth alternate chewing beat. Animation will play neutral idle -> action frames 1 2 3 4 -> 3 2 1 -> neutral idle, so smooth incremental changes are essential. Consistent crisp pixel clusters and silhouette. No other species. No words or labels.
